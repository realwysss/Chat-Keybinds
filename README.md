# Chat Keybinds

up to 4 keys that send a chat message or a command, like `gg` or `/spawn`.

client side fabric mod for minecraft 1.21.11, needs fabric api.

- bind the keys in options, controls, under **Chat Keybinds**
- set a message with `/chatkey <1-4> <message>`, start it with `/` to run a command
- `/chatkey` shows what every key sends, `/chatkey <1-4>` clears one
- key 1 sends `gg` by default, the keys start unbound

## download

`chat-keybinds-mc1.21-1.21.11-1.0.0.jar` on the releases page. minecraft 1.21.11, fabric loader 0.16 or newer.
